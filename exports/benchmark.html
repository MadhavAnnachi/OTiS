Problem definition

Dynamics
Planar point mass (double integrator), state [x, y, vx, vy]: v̇ = (F/m)·u with F/m = 1 m/s², no gravity or drag. Thrust is held constant over each step and integrated with RK4.
Time step
dt = 0.08 s
Horizon
N = 50 steps (T = 4.00 s)
Objective
J = ‖pN − goal‖² + λ·Σk‖uk‖², λ = 0.01; |ux|, |uy| ≤ 1.0 per step
Terminal condition
Soft penalty: the terminal position error is part of J and terminal velocity is free, so OTiS, convex and the KKT optimum trade a small miss for less control effort. E-guidance instead enforces the terminal position exactly (zero-miss rendezvous by construction).
Test missions
5,000 (5 disjoint folds × 1,000), never seen in training
Sampling
Start and goal positions uniform in [−2.0, 2.0]² m; initial velocity uniform in [−0.5, 0.5]² m/s; drawn from random-number streams separate from training's
